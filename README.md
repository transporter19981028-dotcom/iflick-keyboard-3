# iFlick Keyboard (iPhone風フリック入力キーボード for Galaxy Z Fold8)

iPhoneの日本語フリック入力(五十音配置・サイズ感)を再現したAndroid IME(独自キーボードアプリ)です。

## 構成
- `IFlickInputMethodService.kt` — キーボード本体(InputMethodService)。文字入力・削除・改行・IME切替を処理
- `FlickKeyboardView.kt` — 実際に描画・タッチ(フリック)を検知するカスタムView
- `KeyData.kt` — 五十音のフリック配置データ(あ→い/う/え/お など)、濁点/半濁点トグル用データ
- `MainActivity.kt` — キーボード有効化への導線を出すだけの案内画面

## 特徴
- タップで中央の文字(あ/か/さ...)、上下左右フリックでい/う/え/お等を入力(iPhoneと同じ配置)
- 「小゛゜」キーで直前の文字を濁点・半濁点・小文字(っ・ゃ等)にトグル
- 折りたたみ(カバー画面)/展開(メイン画面)どちらでも画面幅に応じて自動リサイズしつつ、
  最大幅を制限してiPhoneに近いキーの大きさ感を維持
- 「123」キーで数字/記号キーボードに切替
- 🌐キーで他の入力方式に切替可能

## ビルド方法(Android Studioが必要です)
このサンドボックス環境はネットワーク制限があり、Android SDK/Gradleの依存取得ができないため、
実際のビルドはお使いのPCのAndroid Studioで行ってください。

1. このフォルダ一式をPCにダウンロードして展開
2. Android Studioで「Open」→ このフォルダを選択(自動でGradle同期・wrapperが生成されます)
3. 上部のデバイス選択でGalaxy Z Fold8(USBデバッグ接続、または実機に直接インストール)を選択
4. 「Run ▶」でインストール & 起動

## Fold8への導入手順
1. アプリを起動し「キーボードを有効化」→ 設定で「iFlick Keyboard」をON
2. 任意の入力欄をタップし、キーボード切替アイコン(または「入力方法を選択」ボタン)から
   「iFlick Keyboard」を選ぶ
